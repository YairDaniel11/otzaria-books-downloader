# הורדת ספרים

תוסף לתוכנת [אוצריא](https://github.com/Sivan22/otzaria) שמוריד ומעדכן מאגר ספרים חיצוני מתוך התוכנה עצמה. המאגר עצמו יושב ב‑[Otzarya-Unofficial-Books](https://github.com/YairDaniel11/Otzarya-Unofficial-Books), והתוסף קורא ממנו את רשימת הספרים, מציג מה חדש ומה השתנה מאז ההורדה האחרונה, ומוריד רק את ההפרש.

## מה התוסף עושה

**עץ הספרים** — כל האוספים והתיקיות שבמאגר, עם הגודל של כל אחד וכפתור הורדה. יש חיפוש חופשי לפי שם או נתיב.

**מעקב אחר עדכונים** — לכל תיקייה במאגר יש חתימת תוכן (hash). התוסף שומר את החתימה של מה שהורדת, ומשווה אותה לחתימה הנוכחית: מה שלא הורדת מסומן "חדש", ומה שהשתנה מאז מסומן "עודכן". הפילטר "הצג חדשים ועדכונים" מציג רק אותם.

**הורדה חלקית** — אוסף שורש נארז כקובץ אחד גדול, אבל לכל תת‑תיקייה יש קובץ משלה. כשמשתנה ספר בודד בתוך אוסף גדול, אפשר לפתוח את שורת "בתוך האוסף" ולהוריד רק את התיקייה שהשתנתה, במקום את האוסף כולו. בסיום, האוסף מפסיק להיות מסומן כדורש עדכון.

**תיקיית הורדה** — נבחרת פעם אחת בכל הפעלה של אוצריא ומשמשת לכל ההורדות שאחריה. אוצריא מתירה לתוסף לכתוב רק לתיקייה שהמשתמש אישר באותה ריצה, ולכן נדרשת בחירה מחודשת בכל פתיחה של התוכנה; בחלון הבחירה מוצגת התיקייה מהפעם הקודמת.

**עמידות** — הורדה שנכשלת מנוסה שוב, ואם היא נכשלת על אוסף שלם התוסף יורד לרמת הילדים ומנסה כל אחד בנפרד, כך שתקלה בפריט אחד אינה מפילה את השאר. כל מה שנכשל מוצג ברשימה עם קישור להורדה ידנית, ואפשר לעצור הורדה ארוכה באמצע.

## התקנה

הדרך הפשוטה היא דרך חנות התוספים של אוצריא, ושם גם העדכונים מגיעים אוטומטית. להתקנה ידנית מורידים את קובץ ה‑`.otzplugin` מעמוד [Releases](../../releases), ובאוצריא נכנסים להגדרות ← ניהול תוספים ← התקנה מקובץ.

לתוסף נדרשת גישת רשת לשלוש כתובות של מאגר הספרים תחת `api.github.com`, `github.com` ו‑`raw.githubusercontent.com`. הן חייבות להופיע ברשימת ההיתר הגלובלית של אוצריא (`plugin_network_allowlist.txt`), אחרת `network.fetch` נחסם ורשימת הספרים לא נטענת כלל.

## פרסום גרסה חדשה

אחרי שמסיימים תיקון או שיפור ודוחפים אותו ל‑main, מפרסמים בדחיפת תג:

```
git tag v3.1.9
git push origin v3.1.9
```

מכאן הכל אוטומטי. הוורקפלואו `.github/workflows/release.yml` מסנכרן את מספר הגרסה ב‑`src/manifest.json` למספר שבתג, בונה את קובץ ה‑`.otzplugin`, בודק שהחבילה תקינה, יוצר Release בגיטהאב, ומעדכן את התוסף בחנות ב‑otzaria.org. אין צורך לערוך את מספר הגרסה ביד — התג הוא מקור האמת, והוא חייב להיות גבוה מהגרסה שבחנות.

הבנייה מסתמכת על שלושה סודות בהגדרות המאגר (Settings ← Secrets and variables ← Actions): `OTZARIA_USER`, `OTZARIA_PASSWORD` ו‑`OTZARIA_PLUGIN_ID`. בלעדיהם שלב הפרסום לחנות מדולג וה‑Release עדיין נוצר.

לבנייה מקומית בלי לפרסם מריצים `build.ps1` ומקבלים `otzaria-books-downloader.otzplugin` בשורש.

## מבנה המאגר

תיקיית `src` מכילה שלושה קבצים: `manifest.json` עם ההצהרות וההרשאות, `index.html` עם הממשק והעיצוב, ו‑`app.js` שמרכז את כל הלוגיקה — טעינת רשימת הספרים, חישוב הסטטוס מול מה שכבר הורד, ההורדה והחילוץ, ותצוגת העץ.
